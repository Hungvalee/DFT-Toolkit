# DFT Toolkit for VASP

A modern Python toolkit for Density Functional Theory (DFT)
calculations using VASP.

## Features

- Geometry Optimization
- SCF
- Band Structure
- DOS
- PDOS
- ELF
- Charge Density
- Charge Density Difference
- Work Function
- Phonon
- Elastic Constants
- AIMD

## Requirements

- Python 3.10+
- VASP 5.4+
- OpenMPI
- VASPKIT
- Phonopy

Install dependencies

pip install -r requirements.txt

## Quick Start

python dft.py version

python dft.py doctor

python dft.py init Graphene
